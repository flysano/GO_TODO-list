# Дипломный проект: Веб-сервер "Планировщик задач"

## Описание проекта

Данный проект представляет собой бэкенд-часть для простого планировщика задач.
Сервер реализует REST API, позволяющее клиентским приложениям создавать, просматривать, обновлять и удалять задачи.
Основная цель проекта — продемонстрировать навыки полученные в процессе обучения Golang, работы с HTTP-запросам и базой данных.

## Основной функционал:
*   Создание задачи с указанием даты выполнения, правил повторения, названия и комментария.
*   Просмотр списка всех задач.
*   Обновление параметров задачи.
*   Удаление задачи.
*   Поиск задач по различным условиям: по дате и по совпадению в названии и комментарии.
*   Хранение данных в реляционной базе данных SQLite.

```

```

### Локальный запуск
```
go build -o GO_TODO-list ./main.go
./GO_TODO-list
```


### Запуск через Docker
#### Сборка образа
```
docker build -t todo-app .
```
#### Запуск контейнера
```
docker run -d \
  --name todo-scheduler \
  -p 7540:7540 \
  -v $(pwd)/data:/app/data \
  -e TODO_PORT=7540 \
  -e TODO_DBFILE=/app/data/scheduler.db \
  todo-app
```

#### Проверка работы
*   После запуска откройте в браузере: [http://localhost:7540](http://localhost:7540)
*   Просмотр логов ```docker logs todo-scheduler```
